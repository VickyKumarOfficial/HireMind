# Create New Job - Quick Reference Guide

## 🚀 How to Create a Job in 5 Minutes

### Step-by-Step Quick Guide

#### 1️⃣ **Open the Form** (5 seconds)
```
HR Portal → Jobs → Click "Create New Job" button
```

#### 2️⃣ **Basic Info** (1 minute)
Fill in the required fields marked with *:
- **Job Title**: e.g., "Senior React Developer"
- **Department**: Select from dropdown
- **Experience Level**: Entry/Mid/Senior/Lead/Principal
- **Employment Type**: Full-time/Part-time/Contract/etc.
- **Work Mode**: Remote/On-site/Hybrid/City

#### 3️⃣ **Job Description** (2 minutes)
- **Description**: Write what the role is about (REQUIRED)
- **Responsibilities**: List duties (one per line)
- **Requirements**: List must-haves (one per line)
- **Qualifications**: List nice-to-haves (one per line)
- **Skills**: Enter comma-separated (e.g., "React, Node.js, AWS")

#### 4️⃣ **Compensation** (1 minute)
- **Min Salary**: e.g., "$100,000"
- **Max Salary**: e.g., "$150,000"
- **Benefits**: List perks (one per line)

#### 5️⃣ **Publish** (5 seconds)
- Click **"Publish Job"** → Live immediately ✅
- OR Click **"Save as Draft"** → Finish later 📝

## 💡 Pro Tips

### ✅ DO:
- Use clear, specific job titles
- Include salary range (attracts better candidates)
- List 3-7 responsibilities
- Be realistic with requirements
- Add company culture in description
- Use bullet points for easy scanning

### ❌ DON'T:
- Use vague titles like "Rockstar Developer"
- Skip salary information
- List 20+ requirements
- Use internal jargon
- Write wall-of-text descriptions

## 📝 Writing Tips

### Job Title Examples
✅ Good: "Senior Frontend Engineer"
❌ Bad: "Code Ninja Wanted"

✅ Good: "Marketing Manager - Growth"
❌ Bad: "Marketing Guru"

### Description Template
```
[Company name] is looking for a [job title] to join our [team name]. 

You'll be responsible for [main responsibility] and work closely with 
[teams/departments]. 

We're looking for someone who [key qualities] and is passionate about 
[mission/values].
```

### Responsibilities Format
```
• [Action verb] + [what] + [why/impact]
• Design user interfaces that improve conversion by 20%
• Lead weekly sprint planning meetings for 5-person team
• Implement automated testing to reduce bugs by 30%
```

### Requirements Format
```
• [X years] of experience in [field/technology]
• 5+ years of experience in React development
• Strong proficiency in [specific skills]
• Experience with [tools/methodologies]
```

```

Level: [Entry/Mid/Senior]
Type: Full-time
Location: Remote

Description:
Join our engineering team to build [product/feature]. You'll work with

• Develop and maintain [systems/features]
• Write clean, testable code
• Participate in code reviews
• Collaborate with product and design teams

Requirements:
• [X]+ years of [technology] experience
• Strong understanding of [concepts]
• Experience with [tools/frameworks]

Skills: [Tech1], [Tech2], [Tech3]

```

## 📊 Tab Organization

### Active Tab
- Shows published jobs
- Displays applicant count
- Shows posted date
- Ready for candidates to apply

### Draft Tab
- Unpublished jobs
- No applicants yet
- Can edit freely
- Has "Publish" button

### Actions Available
| Tab | Available Actions |
|-----|------------------|
| Active | View Applicants, Edit, More Options |
| Draft | Publish, Edit, More Options |

## 🔧 Troubleshooting

### Problem: Can't click "Publish Job"
**Solution:** Fill in all required fields (marked with *)

### Problem: Skills not showing as tags
**Solution:** Separate skills with commas

### Problem: Responsibilities all on one line
**Solution:** Put each responsibility on a new line

### Problem: Form closed accidentally
**Solution:** Click "Create New Job" again (form resets)

## 🎯 Common Scenarios

### Scenario 1: Copying Similar Job
1. Open existing job details
2. Click "Create New Job"
3. Copy/paste relevant sections
4. Modify specific details
5. Publish ✅

### Scenario 2: Creating Multiple Jobs
1. Create first job → Save as Draft
2. Create second job → Save as Draft
3. Create third job → Save as Draft
4. Review all drafts
5. Publish all at once 🎉

### Scenario 3: Need Approval Before Posting
1. Fill out complete form
2. Click "Save as Draft"
3. Share draft for review
4. Make requested edits
5. Click "Publish" when approved ✅
