# Resume Upload - Quick Reference Guide

## 🚀 Quick Start (30 Seconds)

### Upload Your First Resume:
1. Go to **Profile** page
2. **Drag & drop** your resume OR click **"Choose File"**
3. Click **"Upload Resume"** in dialog
✅ Done!

---

## 📤 How to Upload

### Method 1: Drag & Drop (Fastest)
```
1. Open your file manager
2. Find your resume file
3. Drag it to the upload area
4. Drop when area highlights
5. Click "Upload Resume"
✅ Uploaded!
```

### Method 2: File Browser (Traditional)
```
1. Click "Choose File" button
2. Browse to your resume
3. Select file
4. Click "Upload Resume"
✅ Uploaded!
```

---

## 🔄 How to Update

```
1. Click "Update" button on current resume
2. Select new file
3. Confirm replacement
✅ Updated!
```

**⚠️ Warning**: Old resume will be replaced!

---

## ⬇️ How to Download

```
1. Click "Download" button
✅ Downloaded!
```

Your resume downloads with original filename.

---

## 🗑️ How to Delete

```
1. Click trash icon 🗑️
2. Confirm deletion
✅ Deleted!
```

**⚠️ Warning**: This is permanent!

---

## 📋 File Requirements

### ✅ Accepted Formats:
- **PDF** (.pdf) - Recommended
- **Word** (.doc, .docx)

### 📏 Size Limit:
- **Maximum**: 5 MB

### ❌ NOT Accepted:
- Images (.jpg, .png)
- Text files (.txt)
- Other formats

## 🔧 Troubleshooting

### Problem: "Invalid file type" error
**Solution**: Only PDF and Word files accepted. Convert your file.

### Problem: "File size exceeds 5 MB" error
**Solution**: 
- Compress your PDF
- Remove high-res images
- Save with lower quality settings

### Problem: Can't drag and drop
**Solution**: 
- Click "Choose File" instead
- Check browser supports drag-drop
- Try different browser

### Problem: Upload button not working
**Solution**:
- Refresh page
- Clear browser cache
- Try different browser

---

## 💡 Pro Tips

### Best File Name Format:
```
✅ Good: "John_Smith_Resume_2024.pdf"
✅ Good: "Jane_Doe_Software_Engineer.pdf"
❌ Bad: "resume.pdf"
❌ Bad: "final_FINAL_v3.pdf"
```

### Compress Large PDFs:
1. Use Adobe Acrobat (Save As → Reduced Size PDF)
2. Use online tools (smallpdf.com, ilovepdf.com)
3. Print to PDF with lower quality

### Keep Multiple Versions:
- Resume_General.pdf (for general applications)
- Resume_Tech.pdf (for tech roles)
- Resume_Management.pdf (for leadership roles)
